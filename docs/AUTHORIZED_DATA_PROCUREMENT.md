# 授权数据采购路径

更新时间：2026-09-04

## 目标与顺序

第一优先级是每日完整挂牌清单。系统需要稳定房源 ID、可复核链接、挂牌状态和供应方总数，
才能识别新增、降价、重新挂牌与下架。成交和估值数据是第二条独立数据线，不能代替挂牌 Feed。

建议按以下顺序推进：

1. 向上海经纪机构或贝壳开放平台申请上海二手房每日授权导出或 API。
2. 同时向中指申请小区级二手房月度交易数据，用于 P4 与 P5 校准。
3. 用房价网 API 补小区字典、相似挂牌、成交参考、租金和配套，但不把其估值结果当作本系统标签。
4. 上海公共数据开放平台只补官方背景数据，不假设其提供逐套在售房源。

## 已核实的官方入口

| 用途 | 官方入口 | 当前公开能力 | 对接方式 |
| --- | --- | --- | --- |
| 企业级房产数据 | [贝壳开放平台](https://open.ke.com/) | 房价分析、Realdata、房屋数据验真等企业产品 | 申请商务合作并确认是否提供逐套挂牌 Feed |
| 二手房成交基准 | [中指数据 API](https://api.cih-index.com/) | 100 城二手房项目、近三年项目月度交易数据和参考成交价 | 咨询热线 `400 630 6618` 或客户经理 |
| 小区与成交补充 | [房价网 API](https://www.fangjia.com/solution/api) | 小区均价、租金、相似挂牌、成交参考、楼盘字典和配套 | 申请试用；官方咨询 `138 1669 2251`、`support@fangjia.com` |
| 官方背景数据 | [上海市公共数据开放平台](https://data.sh.gov.cn/) | 可下载或申请调用的无条件开放公共数据 | 注册后按数据集申请；客服 `sjkf@shanghai.gov.cn` |

中指项目 API 可直接补交易基准，但公开说明不是每日逐套挂牌 Feed。房价网采用短期 token，且
接口按小区或估价场景组织，接入前需要供应方确认调用配额与批量覆盖方式。两者都不能在合同未
明确授权前当作全市场挂牌扫描源。

## 首轮询价范围

请求一份连续 7 天的试用数据：

- 上海二手住宅在售房源；
- 徐汇、闵行、普陀、杨浦、浦东；
- 总价 230 万至 330 万元；
- 每日一次完整快照，预计 500 至 3000 套；
- 不含业主姓名、手机号、身份证、精确门牌等个人信息；
- 允许内部研究、模型验证、原始记录留存和派生评分；
- 明确是否允许保存下架记录和历史价格变化。

最低字段与系统 Canonical 1.x 一致：稳定房源 ID、URL、区、板块、小区、总价、面积、户型、
楼层、总楼层、朝向、建成年代、电梯、挂牌状态、观测时间。经纬度、挂牌日期、带看量、核验标识
与物业属性建议一并提供。

## 交付验收

API 供应方需提供 HTTPS 地址、认证方式、分页规则、总数语义、限流规则、状态字典和脱敏样例。
逐套记录必须提供带时区的观测时间；LIVE 接口默认拒绝超过 36 小时的快照。
CSV 供应方需每天投递完整文件及供应方控制总数，项目侧使用
`scripts/prepare_partner_csv_manifest.py` 做逐行 Canonical 校验、唯一性校验、时间边界与 SHA-256
验真。首周保持人工监督；连续 7 次完整运行后再切为无人值守 LIVE。

项目不会索取或保存业主个人信息，也不会绕过登录、验证码、访问限制或网站授权边界。
